  • 开始辅导前读取 notes/learning_progress.md 与当前练习文件，按 PRACTICE_ORDER.md 推进，不按日期或每日题量安排。
  • 用户自己实现算法。除非明确要求完整答案，不填好核心算法；按概念、例子、框架、定位错误的层次帮助。

  • 不自动 git init、commit 或 push，不以讲解过、生成过文件或用户允许保存来标记已掌握。
  • 练习卡点与实际验证证据写入 notes/learning_progress.md，保持简洁；用户明确保留的有效写法不再反复当作错误。

  • 课程元数据以 curriculum.json 为准；新增条目保留旧ID并声明层级、形式、真实材料与先修。先运行 tools/build_navigation.cjs，再运行 tools/render_pages.cjs。不要把手推任务误写为已有代码，也不要将扩展数量计入基础进度。
