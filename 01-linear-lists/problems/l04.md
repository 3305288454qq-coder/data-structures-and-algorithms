## 要求

使用不带头结点的单链表。实现按 1 开始的位序插入、删除、查找与销毁；非法位置返回 false；销毁后 head 必须为空。

这是为本地练习编写的任务说明；在线题链接用于追加提交验证，不表示两个入口的接口完全相同。

## 接口与已有内容

```cpp
bool list_insert(ListNode*& head, int position, int value);
bool list_erase(ListNode*& head, int position, int& removed);
ListNode* list_at(ListNode* head, int position);
void destroy_list(ListNode*& head);
```

所需结构体在 [common.hpp](../../templates/common.hpp) 中。代码文件已经准备好上述接口和一个 main 自测入口；只需实现 TODO，先不要删除异常去假装完成。使用 0 基下标还是 1 基位序，以本页为准。

## 输入输出示例（用于理解）

下面保留原来的演示调用，便于理解输入输出；当前 main 已升级为多组自动断言，不再逐行打印这些示例：

```cpp
ListNode* head = nullptr;
std::cout << list_insert(head, 1, 10) << '\n';
std::cout << list_insert(head, 2, 20) << '\n';
std::cout << list_at(head, 2)->value << '\n';
int removed = 0;
std::cout << list_erase(head, 1, removed) << ' ' << removed << '\n';
destroy_list(head);
std::cout << (head == nullptr) << '\n';
```

如果单独使用上面的演示调用，预期输出为：

```text
1
1
20
1 10
1
```
