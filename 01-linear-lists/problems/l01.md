## 要求

用固定容量顺序表实现按位查找、插入、删除。位序从 1 开始；非法操作返回 false 且不改变表。删除成功时用引用参数返回被删值。

这是为本地练习编写的任务说明；在线题链接用于追加提交验证，不表示两个入口的接口完全相同。

## 接口与已有内容

```cpp
bool get_element(const SqList& list, int position, int& value);
bool insert_element(SqList& list, int position, int value);
bool erase_element(SqList& list, int position, int& removed);
```

所需结构体在 [common.hpp](../../templates/common.hpp) 中。代码文件已经准备好上述接口和一个 main 自测入口；只需实现 TODO，先不要删除异常去假装完成。使用 0 基下标还是 1 基位序，以本页为准。

SqList list;
