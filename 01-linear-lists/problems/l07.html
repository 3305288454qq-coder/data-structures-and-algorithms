L07 双向循环链表

要求

使用带哨兵的双向循环链表；空表时哨兵 prev、next 都指向自身。实现尾插、删除首个匹配值、清空，清空不删除哨兵。

这是为本地练习编写的任务说明；在线题链接用于追加提交验证，不表示两个入口的接口完全相同。

输入输出示例（用于理解）

下面保留原来的演示调用，便于理解输入输出；当前 main 已升级为多组自动断言，不再逐行打印这些示例：

DoubleNode sentinel;
sentinel.prev = sentinel.next = &sentinel;
append_node(sentinel, 10); append_node(sentinel, 20);
std::cout << erase_first(sentinel, 10) << '\n';
std::cout << sentinel.next->value << ' ' << sentinel.prev->value << '\n';
clear_nodes(sentinel);
std::cout << (sentinel.next == &sentinel && sentinel.prev == &sentinel) << '\n';
