G11 遍历整个图与连通分量

本章目录 · 练习导航 · C++ 框架

基础｜编码｜王道主线。学习状态：未开始；材料建立不表示掌握。

为什么练

单起点 DFS/BFS 会漏掉不可达顶点；外层再选择未访问顶点，才能得到全图遍历森林。

前置：G02。仅无向图；邻接表已对称，允许自环与重复边。分量按其中最小顶点升序编号，分量内升序返回。

接口与任务

connected_components(graph) 返回分量列表。内部可用 DFS 或 BFS，但最终按接口排序，从而把“合法遍历顺序不同”与“结果错误”分开。

六个顶点，边 0—1、1—2、3—4，结果为 [[0,1,2],[3,4],[5]]。5 是孤立顶点，也单独形成一个分量。空图没有分量。

要解释的区别

连通分量的这个定义针对无向图；在有向图里机械照搬会混淆强连通与弱连通。访问标记什么时候置位，才能避免重复入队或在环上无限递归？

测试

三个分量、空图、全孤立、含重复边和自环。遍历本身 O(n+m)，为固定输出顺序额外排序的开销另计。

验收与下一步

代码中的 main 会核对普通情况与边界；返回 0 表示这些自测通过，1 表示已实现但核对失败，2 表示还有 TODO。测试通过仍需解释复杂度与关键不变量；不要只删除 TODO 异常。
