G10 邻接矩阵与两种存储的转换

本章目录 · 练习导航 · C++ 框架

基础｜编码｜王道主线。学习状态：未开始；材料建立不表示掌握。

为什么练

给 G01 缺少的矩阵版本建立独立接口，比较边查询和邻接点枚举的代价。

前置：G01。顶点为 0..n-1，n≥0；输入边合法。无权有向图，重复边合并成 1，自环保留。

接口约定

make_matrix(n, edges) 返回 n×n 的 0/1 矩阵；matrix_to_list(matrix) 每行按顶点编号升序列邻接点。不要把“无边”的 0 与带权图中的零权边混用。

先手推再写

n=3，边 (0,2)、(0,1)、(0,2)、(2,2)，矩阵依次为 [0,1,1] [0,0,0] [0,0,1]；邻接表为 [[1,2],[],[2]]。先实现矩阵建表，再转换。

已准备检查

普通图、无边、空图、自环、重复边、矩阵行列尺寸。说明矩阵 O(n²) 空间和转换扫描 O(n²)；不要拿邻接表的 O(n+m) 直接套用。

验收与下一步

代码中的 main 会核对普通情况与边界；返回 0 表示这些自测通过，1 表示已实现但核对失败，2 表示还有 TODO。测试通过仍需解释复杂度与关键不变量；不要只删除 TODO 异常。
