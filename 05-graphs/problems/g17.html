G17 负边、强连通分量与割点/桥

本章目录 · 练习导航

扩展｜手推｜课外扩展。已有具体任务与核对材料；没有专用 C++ 框架，未确认掌握。

目标与约定

这三类课外图题分别补充负权路径、有向互达、无向网络关键位置，按兴趣选一类深入。

前置：G11、G13、G07。手推任务互相独立，不要求三种代码一起写。割点/桥例子为无向简单图。

A：Bellman–Ford 与负环

顶点 0、1、2，边 0→1(4)、0→2(5)、1→2(-2)。从 0 出发，逐轮列出松弛后的距离。再加边 2→1(-3)，解释为什么 1、2 没有有限最短距离。最后另加独立的负环 3↔4，但不与 0 连通：单源问题应如何区分？

核对 A

原图结果为 [0,4,2]。新环 1→2→1 总权 -5，从 0 可达，因此可反复降低 1、2 的距离。与源点不可达的 3、4 负环不影响从 0 的可达最短路径；但“全图是否存在负环”是另一种问题，可用超级源点改变检测范围。

B：强连通分量与缩点

边 0→1、1→2、2→0、2→3、3→4、4→3。画出互相可达的最大点集，再把每个点集收缩成一个顶点。结果为什么不可能还有有向环？选择 Kosaraju 或 Tarjan 再阅读实现，但先别混淆普通访问标记和“仍在栈内”。

核对 B

分量为 {0,1,2} 与 {3,4}，缩点后只有从前者到后者的一条方向。如果多个不同分量仍能构成环，它们就互相可达，和“最大分量”矛盾。

C：割点与桥

无向三角形 0—1—2—0，另接 2—3—4。逐个删除一个顶点或一条边，数连通分量变化，再尝试用 DFS 发现时间/low 值解释。

核对 C

割点为 2、3；桥为 2—3、3—4。三角形内部任意删一条边还有替代路径。DFS 根的割点判据与非根不同；有平行边时还须按边编号跳过父边，不能跳过所有“通向父顶点”的边。
