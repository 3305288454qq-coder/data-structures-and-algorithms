G12 BFS 最短距离与路径恢复

本章目录 · 练习导航 · C++ 框架

基础｜编码｜王道主线。学习状态：未开始；材料建立不表示掌握。

为什么练

无权图中按层扩展得到最少边数；保存前驱后才能回答“具体怎么走”。

前置：G02、S03。有向或无向无权图；邻接点顺序任意。有效起点；空图以 source=-1 表示。不可达距离/前驱均为 -1，起点前驱为自身。

两个接口

bfs_paths(graph, source) 返回 distance 与 parent 两个数组。restore_bfs_path(result, source, target) 返回顶点序列；不可达或空图返回空序列，起点到自身为一个顶点。

具体例子

边 0→1、0→2、1→3、2→3，另有孤立顶点 4。距离是 [0,1,1,2,-1]。到 3 的 [0,1,3] 与 [0,2,3] 都正确；测试核对边与长度，不强求某一条。

最先到达顶点时记录 parent。恢复时从终点沿 parent 回走，再反转；为什么不能只按距离递减而不检查边？先实现距离，再实现恢复。

已准备检查

多条等长最短路、起点自身、不可达、空图、含环。O(n+m) 求距离，一条路径恢复 O(路径长度)。

验收与下一步

代码中的 main 会核对普通情况与边界；返回 0 表示这些自测通过，1 表示已实现但核对失败，2 表示还有 TODO。测试通过仍需解释复杂度与关键不变量；不要只删除 TODO 异常。
