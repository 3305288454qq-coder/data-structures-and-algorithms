## 为什么练

用有向无环图共享相同子表达式，并让每个运算结点只求值一次；把图知识与编译器优化联系起来。

前置：G07、B01。结点类型限定常数、+、-、*；编号不保证拓扑有序；输入从根可达部分无环，所有中间结果适合 long long。

## 结构与任务

常数结点保存 value；运算结点保存 left、right 两个子结点编号。边从运算指向依赖项；与“先修课→后继课”的方向不同，求值顺序应是依赖先于使用者。

`evaluate_dag(nodes, root)` 返回 value 和 evaluated（各结点实际计算次数）。使用记忆化 DFS 或合适的逆向拓扑处理；不可达结点保持 0 次。

例：u=(2+3)，根=u×u。普通展开树会复制 u；DAG 让根的左右指向同一个 u。预期结果 25，2、3、加法、乘法各计算一次。根编号可以是 0，不要直接按数组顺序算。

## 第一小步

先画出四个结点与边，区分“访问了两次同一编号”和“真正计算了两次”。测试使用计数数组检查共享，而不只检查最后数字。空图配 root=-1，返回 value=0、空计数。

代码中的 main 会核对普通情况与边界；返回 0 表示这些自测通过，1 表示已实现但核对失败，2 表示还有 TODO。测试通过仍需解释复杂度与关键不变量；不要只删除 TODO 异常。
