# X14 桶排序、三路快排与算法选择

[练习导航](../../index.html)

**扩展｜阅读与手推｜学习状态由实操确认**


计数排序适合值域受控的整数；桶排序先按规则分组，再处理桶内次序；三路快排把数据分成小于、等于、大于枢轴三段，适合大量重复值的情形。
这不是“高级名字必然更快”：桶若分布严重不均，桶内工作可能很重；计数排序值域过大时额外空间不合算。

## 自己选方法并说明条件
- 一百万条年龄记录，值域0到150。
- 一百万个都相等的整数。
- 很少的整数，但最小最大值相差十亿。
- 只需要第100小的数，不要求其余数完整排序。

<details>
<summary>对照思考方向</summary>
受限值域可考虑计数；大量重复值可考虑三路划分；跨度大但元素少不宜直接开巨大计数数组；只求第k小可看R18快速选择。
这些是选择依据，不是对任何语言和机器的绝对速度保证。
</details>

## 可选实验
在相同输入和构建选项下比较比较次数、移动次数、额外空间；计时要重复且避免把生成数据和打印混进算法耗时。
先确认输出正确、元素不丢不重，再讨论性能。完整实现可按兴趣开展，不影响基础路线。
