X08 线段树：点赋值与区间和

练习导航 · C++ 框架 · 测试说明

扩展｜编码｜已有框架与自动自测｜未开始，不计入基础完成率。

为什么练

实现动态区间查询，明确结点区间、递归边界和合并信息。

约定与目标

查询为半开区间[left,right)，0≤left≤right≤n；空输入可查询[0,0)。更新位置必须合法，point_set是赋值不是累加。建树 O(n)，点更新与区间查询 O(log n)，存储 O(n)。

先想清楚

每个结点保存所管区间的和。查询区间与结点区间可以不交、全含或部分重叠；分别处理。

具体例子

1,2,3,4的[1,3)和为5；把第2项设为-3后总和4。

函数接口

SumTree build_sum_tree(const std::vector<int>& values);
void point_set(SumTree& tree, int position, long long value);
long long interval_sum(const SumTree& tree, int left, int right);
