X03 二分答案：最小运输容量

练习导航 · C++ 框架 · 测试说明

扩展｜编码｜已有框架与自动自测｜未开始，不计入基础完成率。

为什么练

包裹按原顺序分批，每天一批；求在给定天数内运完的最小容量。

约定与目标

重量为正，days≥1；空输入返回0；不能拆包或改变顺序。返回 long long，目标 O(n log(sum))。

先想清楚

先给一个候选容量，判断是否能按天数限制运完，再说明可行性为什么随容量增大保持成立。

具体例子

1,2,3,4,5，2天：容量9可分为1+2+3和4+5；容量8不能。

函数接口

long long minimum_capacity(const std::vector<int>& weights, int days);

结构与测试已准备，函数中的 TODO 留给你实现。首次运行应为“未完成”，不能仅删除 TODO 来伪装成功。

main 已含普通和边界断言；失败会报告用例标签。有限用例通过以后，仍要自己解释复杂度、关键不变量与适用条件。
