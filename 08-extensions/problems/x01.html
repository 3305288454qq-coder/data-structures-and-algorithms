X01 前缀和与区间求和

练习导航 · C++ 框架 · 测试说明

扩展｜编码｜已有框架与自动自测｜未开始，不计入基础完成率。

为什么练

预处理一次，回答多个半开区间 [left,right) 的和；用 long long 保存累计值。

约定与目标

输入整数数组；查询满足 0≤left≤right≤n。构造返回 n+1 项，prefix[0]=0。构造 O(n)，一次查询 O(1)。

先想清楚

prefix 的第 0 项表示空前缀。先明确 prefix[i] 表示前多少个元素，再推两个前缀之差。

具体例子

输入 2,-1,4,3；区间 [1,3) 包含 -1,4，和为3。

函数接口

std::vector<long long> make_prefix(const std::vector<int>& values);
long long range_sum(const std::vector<long long>& prefix, int left, int right);
