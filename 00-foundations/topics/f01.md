# F01 复杂度与递归空间自检

[练习导航](../../index.html)

**基础｜阅读与手推｜学习状态由实操确认**


你已经听完课程，这页用于碰到复杂度问题时自检，不要求先重学理论才写题。
时间复杂度描述输入规模增长时的操作数量级；实测秒数还受数据、编译与机器影响。空间分析要说明是否包含输入、输出和递归栈。

## 三道短题
1. 外层 i 从 0 到 n−1，内层 j 从 0 到 i−1，累计执行多少次？能否只因“有两个循环”就判断任何代码都是 O(n²)？
2. 每次把 n 除以 2，直到 n≤1，循环多少次？
3. 对二叉树做递归遍历，访问 n 个结点。平衡树和单链形树的最大递归深度是否相同？

<details>
<summary>展开核对</summary>
第一题次数 n(n−1)/2，增长量级 O(n²)。嵌套循环的边界、步长和依赖关系必须实际分析。
第二题为对数级；不能因为只有一个循环就写 O(n)。
第三题时间都是 O(n)，调用栈是 O(h)；平衡时 h 为对数级，单链时可为 n。输出数组若保存所有结点，另外占 O(n)。
</details>

## 与现有练习关联
顺序表插入看移动多少元素；二分查找看每轮剩余范围；树遍历看每个结点访问次数；外排序还要计读写，而不只是比较。
完成标准：挑一份你自己的函数，说明基本操作、最坏输入、额外空间，并指出递归空间在哪里。
