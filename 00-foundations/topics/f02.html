这些概念按需要查，不要求一次背完。vector 是可变长度容器；size() 是当前元素数，capacity() 是已分配容量，两者不同。v[i] 不自动检查越界，合法范围是 0 到 size()−1。

const vector<int>& 表示借用一组只读数据，通常避免整组复制；vector<int>& 可以修改调用者的数据。按值传递得到独立副本，适合某些会排序或重新排列输入的题。

Node*& 是“指针变量的引用”，适合需要把调用者的头指针改成另一个地址的操作；普通 Node* 仍可以通过地址改结点，但只给该局部指针重新赋值不会改变调用者的指针变量。

自己判断

  • 空 vector 的 size() 是 0，访问 v[0] 是否合法？
  • 在 main 里写 TreeNode root{1};，算法可以对 &root 执行 delete 吗？
  • 用 new 创建链表结点之后，只把 head 设为 nullptr 是否释放了结点？
  • 函数通过引用参数返回被删除的值，与函数返回 bool 的成功标志有什么不同？
展开核对

1 不合法；2 不能，栈对象不由 delete 释放；3 不会，仅丢失了入口可能造成泄漏；4 两者可同时使用，一个带回数据，一个说明操作成败。

练习前先看契约

结点由谁创建、由谁释放；头结点是否存有效值；位序是否从 1 开始；下标是否从 0 开始；不合法输入如何处理。不要把不同题的约定混在一起。
