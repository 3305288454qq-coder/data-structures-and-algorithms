## 接口与已有内容

```cpp
bool push(ArrayStack& stack, int value);
bool pop(ArrayStack& stack, int& value);
bool peek(const ArrayStack& stack, int& value);
```

所需结构体在 [common.hpp](../../templates/common.hpp) 中。代码文件已经准备好上述接口和一个 main 自测入口；只需实现 TODO，先不要删除异常去假装完成。使用 0 基下标还是 1 基位序，以本页为准。
