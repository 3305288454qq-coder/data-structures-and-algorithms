# 顺序查找：逐项检查与失败代价

[Q01 问题](../06-searching/problems/q01.md) · [练习导航](../index.html)

顺序查找不要求数组有序。从规定的起点逐项比较目标，找到符合要求的位置后返回；本题要求第一次出现的0基下标，找不到返回−1。
它与折半查找不同：不能因为二分更快，就对任意未排序数据直接折半。

例如 8、3、8 中查8，返回0；查3返回1；查9返回−1。空数组也应返回−1，不访问第0项。
普通逐项比较的最坏次数为n。平均查找长度必须说明成功/失败及各键被查概率；在每个位置等概率成功的模型下，成功比较次数平均为(n+1)/2。

哨兵实现通过额外安排一个保证能匹配的位置减少某些边界判断，但会改变存储或操作约定；不能在只读输入接口里擅自越界写入。
先完成普通版本，再比较是否有足够的额外位置、原值如何恢复、失败如何识别。不把“少写一个条件”当成改变O(n)数量级。
