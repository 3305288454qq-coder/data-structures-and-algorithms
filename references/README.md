## 已核对的主要入口

- [OI Wiki](https://oi-wiki.org/)：算法讲解、复杂度与参考实现。
- [Dotcpp 数据结构题库](https://www.dotcpp.com/oj/ds/)：学校基本操作风格的题目，支持代码提交，网站展示顺序与这里不同。
- [洛谷题单](https://www.luogu.com.cn/training/list)：线上判题与模板题。本目录已挑选与王道主题相关的题，不要求按竞赛目录从头刷。
- [力扣](https://leetcode.cn/problemset/)：指定函数/类接口的算法题。
- [旧版王道/天勤代码参考](https://github.com/lcl100/data-structure-learning)：个人整理，包含 2022 版部分题的 C/Java 实现；不是王道官方 2027 配套判题站。

## 适用边界

本目录的问题文字为自编的实现要求，在线原题通过链接引用；以原题最新接口、输入输出和范围为准。已经读取题库与参考页面，不代表代你提交过或验证过网站的隐藏测试。

网站可能有登录要求。这里没有复制第三方题解代码；示例和框架用于你自己的练习。
