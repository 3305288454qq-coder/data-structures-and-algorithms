R19 受限内存文件外排序实验

本章目录 · 练习导航 · 外部排序专题

扩展｜实验｜配套深化。已有任务与验收规范，没有目标算法完整实现。未确认掌握。

目标与前置

把内存模拟接成真正的分段文件、缓冲和多轮归并，同时测量记录守恒、内存占用与逻辑块读写。

前置：R14、R15、R16、R17。只在本章 external/lab-work/ 自建实验目录中操作；输入文件只读，输出另存，不覆盖练习源文件。

固定输入与格式

文件每行一个十进制 int。先使用 32 条小样本，对应 排序后结果。小样本包括重复、负数、INT_MIN/MAX；约定本实验不携带身份，因此不要求稳定。

大样本 N=200000，第 i 条（i 从 0 开始）为 (i×48271 mod 1000003)−500001；乘法先使用 long long。自己写一个独立生成器，逐条写 source-data.txt。额外生成升序、降序和全相同三组输入。不要先把整份数据读进 vector 再声称做了外排序。

内存与缓冲预算

算法持有的数据结构和显式读写缓冲合计上限 64 KiB；这不是要求整个 C++ 进程只占 64 KiB。记录 vector 的容量、每项大小、堆或败者树、冻结标记、输入输出缓冲占用；库内部流缓冲与进程开销另列，不隐瞒。

初始段候选容量先取 M=4096 个 int。归并先取 k=4，每条输入段缓冲 256 个 int，输出缓冲也 256 个 int。不要把初始段工作区与归并工作区无必要地同时保留。解析文本只保留当前行，拒绝畸形/超长整数；本题给定输入合法，异常处理可后补。

建设步骤（按顺序，不按时间）

  • 先固定分块生成有序段，每段最多 M 个；确认所有段有序、记录数总和=N。
  • 对两个段做缓冲归并，再推广到 k 路；段多于 k 时生成下一轮文件，直到只剩一条段。
  • 接入 R15 置换—选择，比较同一输入的初始段数；不要假设总能减半。
  • 分别用小根堆与 R16 败者树选择候选，计数关键字比较；采用同一输入/缓冲/计数口径。
  • 段长度不同后，用 R17 安排归并次序；检查最优加和模型与受限实际调度的差别。

验收

  • 小样本逐行与 expected 文件一致，空输入与单记录也正确。
  • 大样本输出逐项非递减，记录数为 N；用已知生成公式统计各键频数核对守恒，或由独立验证程序用内存排序对照。验证器可占较多内存，不能把它混成受限排序算法本身。
  • 任意时刻显式内存不超过预算；峰值依据真实容器 capacity 和缓冲大小记录，不能只填配置值。
  • 临时段命名含运行编号，失败不覆盖原始输入；只有核对完成后才自行清理本轮临时段。
  • 报告每种方法适合何种输入，不以一次机器运行结果宣布某数据结构永远更快。
