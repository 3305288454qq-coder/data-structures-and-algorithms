目标与前置

保留已有 pi 版 KMP，理解不同数组定义并用 next 完成首次匹配。

前置：T03。已有 T03 不被替换；有效的 pi 实现不是错误版本。

接口约定

pi[i] 是模式 0..i 的最长相等真前后缀长度。这里 next[j]（j 从 1 开始）表示模式第 j 个字符失配时，下次尝试的 1 基模式位置；next[1]=0，0 是哨兵，next[0] 为未使用占位。pi_to_next 返回 m+1 项，空模式返回 {0}。输入 pi 保证合法。find_with_next 的文本、模式仍是普通 0 基 std::string，内部采用 1 基 j；返回首次匹配的 0 基起点，失败返回 -1，空模式返回 0。不要把 pi 的数值直接当 next 使用。

先手推再实现

手推 pattern="ababa"：逐格填写 pi，分别解释“已匹配到第 3 个字符之后的公共前后缀长度”与“第 3 个字符失配后跳到哪里”。对照答案在专题页折叠区，先写自己的表。

已备测试与复杂度

空模式、单字符、无匹配、重复前缀、模式长于文本、起始与末尾匹配。

main 含自动核对；表转换 O(m)；匹配 O(n+m) 时间，除传入表外 O(1) 额外空间。
