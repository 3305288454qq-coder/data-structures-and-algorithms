打开文件夹

在 VS Code 中选择“文件 → 打开文件夹”，打开 D:\\Data Structures and Algorithms。

也可以用“文件 → 从文件打开工作区”打开本目录的 Programming Practice.code-workspace，一起显示基础编程练习、数据结构与算法、工具练习三个目录。它只记录打开哪些文件夹，不复制或合并代码。

编译、运行、调试

先选中并保存你正在练习的 .cpp 文件，例如 01-linear-lists/code/l01.cpp：

  • Ctrl+Shift+B：编译当前文件。程序输出放在 build/ 的同名子目录中。
  • Ctrl+Shift+P：这是“命令面板”，可以按名称找 VS Code 的操作。输入“运行任务”，选择“任务: 运行任务”，再选择 Run active C++ file；此任务先编译后运行。
  • F5：选择 Debug active C++ file。已准备本目录自己的调试配置，不必重新生成“cl.exe 生成活动文件”。程序会先停在入口；F10 单步，F11 进入函数，F5 继续运行。
  • 断点：在代码行号左边点一下，出现红点；程序暂停后，左侧“运行和调试 → 变量”显示当前作用域的变量，也可把鼠标放到变量名上。

要求已安装 Microsoft C/C++ 扩展。配置使用本机 D:\\Visual Studio2026 下的 MSVC，C++17、调试符号、无优化和警告；仅影响本目录，不改系统环境变量。

为什么第一次运行显示 TODO

框架中的 todo(...) 会抛出异常，由 main 显示消息并以状态 2 退出。这明确表示目标算法还没有实现。完成函数中的逻辑后移除对应占位调用；不要只删除它来获得“运行成功”。函数里 (void)参数名 是防止空框架产生未使用参数警告的临时语句，填好函数后可移除。

本地练习与在线提交

95个编码框架已准备多组自动核对；问题页说明接口、边界和复杂度。实际运行会区分 TODO（尚未实现）、FAIL（核对失败）、PASS（当前测试通过）。通过现有测试仍需检查边界和复杂度，具体见 自测与结果说明。

  • 力扣：保留平台给的类、函数签名、字段名，通常只提交算法，不提交本地 main。
  • 洛谷、Dotcpp：根据原题读入输入并输出结果，通常提交完整程序。
  • 本地通用结构体、容量、0 基下标、int 类型不一定符合在线题；查看问题页的适配提醒和原题约束。
  • 在线题要求标准输入输出时，删除自测固定数据和调试打印。

P4779 是堆优化阶段选做题，不能用朴素 Dijkstra 的超时判断逻辑错误；P1177 数据较大，不能要求 O(n²) 排序通过全部点；KMP 的前缀函数与王道不同版本的 next 要先对齐定义。

保存进度

导航默认显示基础内容，可以切换为进阶、扩展或全部，并按练习方式筛选。搜索同样受筛选限制；找不到计数排序等条目时，先点击“清除筛选，查看全部”。先修编号可以直接点击跳转。

在导航中按实际表现选择学习状态，展开“记录卡点 / 验证证据”写笔记；浏览器只保存本地记录，不修改代码或Markdown。JSON是完整备份，可以在另一个浏览器导入，导入默认保留重叠的本地记录。Markdown导出适合阅读，不能完整恢复所有状态和笔记。

需要换对话时，由负责本章的AI在 notes/learning_progress.md 维护交接；你不必在多个文件重复勾选。PRACTICE_ORDER.md仅作顺序总览，网页状态为可选个人记录，两者不会自动同步，也不会因讲解过便认定掌握。

每章开一个新对话

日常仍从index.html开始。首页上方展开“复制这段话给新的ai对话或者工作区”，点击“复制完整辅导与 Notion 整理提示”，粘贴到新对话，填写章节和当前问题即可。正文与AGENTS.md一致，统一维护。

同一工作区的新AI按提示读取学习记录中的本章交接和实际代码；普通聊天或换设备时，再附上一段本章交接及必要的题面/代码。文件读取不到就先提供需要的内容，不要求假装同步。

可以这样开头：“这是树与二叉树章节，继续B08。请先读本章交接和保存的代码，再帮我检查栈的使用。”

做题、问概念和求助都不要求你同时维护多份进度。网页状态可按需记录；负责本章的AI在学习记录维护接续信息。Notion正式笔记仍先纠错、给出拟稿和位置，经确认才写入。
